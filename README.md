
# LM.RT

**Rural × Tailor**

A Japanese menswear label working at the intersection
of rugged function and the craft traditions of classic tailoring.

[lm-rt.com](https://lm-rt.com)


---

### About

LM.RT is a Tokyo-based menswear brand. The work sits between two
sensibilities — the durability and rawness of the rural, and the
precision and restraint of the tailor's hand. We build clothing, and
the systems behind it, with the same regard for both.

### Here on GitHub

This organization holds the engineering work behind the brand —
storefront, infrastructure, and the tooling that connects them.
Most repositories are private during this phase.
